# data (untracked, regenerable)

Generated by `vox/generate.py` (gesture decisions) and `vox/targets.py` (intent-cursor targets). The output is deterministic for a given code version and seed. Each version folder holds `train`, `validation`, `test_iid`, `test_unseen_phrasing`, `test_unseen_apps` (`.jsonl`) and `policy.txt`.

| Version | What changed | Tests |
|---|---|---|
| v0 | First generator; rules quote the option text, so scores are inflated | own |
| v1 | Paraphrased action wordings | own |
| v2 | Rich training wordings | copies of v1's |
| v3 | 4 label bugs fixed | new |
| v4 | v3 + the filtered LLM wording bank | identical to v3 |
| v5 | The target task: new defaults (hiss = back, long flat hum = long-press), screen line, screen_phrase kind, cursor-mode actions removed (button only), 30% of rows list all options in table order; `*.fullopts.jsonl` test copies. **Regenerated 2026-09-26 09:02**; runs trained before that are stale | new |
| v6 | v5 + popclick bindings: click=tap, click click click=listen, pop never emitted | new |
| targets-v1 | Intent cursor target picking | own; superseded |
| targets-v2 | Tree roles match the emulator harvest; doubled-word fix | own |
| targets-v2t | targets-v2 + opt-in tree screens (`--tree`): v2 option format (indented-list context + column/row rank); ~40% of rows are tree rows, the rest are flat rows with v2 rank | own |

Regenerate:
```bash
python -m vox.generate --output data/v5 --bank wordings_llm/bank.json
python -m vox.targets --output data/targets-v2
python -m vox.targets --output data/targets-v2t --tree
```
Never regenerate a version while something trains or evaluates on it. Make a new version instead.
