# Decisions log

Every decision the user made while VOX / Canti was built, newest first, plus the decisions agents made inside their own
work (at the bottom). Times are UTC. Some repo documents (for example `finetune/data/real-targets-v2/SPLIT.md`) use local
time, which is UTC−4 (inferred: SPLIT's "20:41" amendment matches the 00:39Z question).

Each row gives:
- the question and the options offered;
- what the user chose, in their own words (shortened);
- the reason or effect, and who carried it out;
- links: "⇠" means this decision replaces an older one, and "⇢" means a newer one replaced it.

Free-text instructions that settled something are included and marked *(free text)*. Questions the user dismissed are
logged too, because "don't proceed" is also a decision. Agent ids are the first 7 characters; see
[agent-log.md](agent-log.md) for the full list.

Sources: the main session transcript (AskUserQuestion answers and user messages), the agent transcripts, and the repo
documents cited in each row.
